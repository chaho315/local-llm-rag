# 폐쇄망 로컬 LLM RAG 챗봇 — 리눅스 설치·셋업 가이드

Windows(PoC)에서 검증한 구성을 **리눅스(Rocky Linux 8/9, RHEL 계열 기준)** 에 그대로 재현하기 위한
순서별 명령어 모음입니다. 각 단계의 명령 블록은 **위에서부터 순서대로 복사·붙여넣기** 하면 됩니다.

> 구성: `Ollama + Qwen3-4B(채팅) + Qwen3-Embedding(검색) + MySQL 8.4(OLLAMA_LLM) + FastAPI 챗봇`
> 연동 방식: **RAG** (모델 재학습 아님. DB/문서를 벡터로 색인 → 질문 시 근거로 제공)

- 계정/스키마(이 문서 기준): DB 스키마 `OLLAMA_LLM`, 앱 계정 `llmuser` / `CHANGE_ME_PASSWORD` (읽기전용), `root` / `CHANGE_ME_PASSWORD`
- 실행 주체: **sudo 권한이 있는 일반 사용자** (root로 직접 로그인 X)

## [0] 공통 변수 (★ 먼저 이 블록을 실행한 뒤, 같은 터미널 세션에서 이어서 진행)

```bash
# 설치 루트 (원하면 변경)
export BASE_DIR="$HOME/llm"
export MODELS="$BASE_DIR/models"          # GGUF 원본
export MF="$BASE_DIR/modelfiles"          # Ollama Modelfile
export RAG="$BASE_DIR/rag"                # RAG 앱

# MySQL (포터블 tarball 방식 기준)
export DB_DIR="$BASE_DIR/db"
export DB_BASE="$DB_DIR/mysql"            # MySQL 프로그램 위치
export DB_DATA="$DB_DIR/data"             # 데이터 디렉토리
export DB_CNF="$DB_DIR/my.cnf"            # 설정 파일
export DB_SOCK="$DB_DIR/mysql.sock"

# DB 접속값
export DB_SCHEMA="OLLAMA_LLM"
export DB_APP_USER="llmuser"
export DB_APP_PW='CHANGE_ME_PASSWORD'
export DB_ROOT_PW='CHANGE_ME_PASSWORD'

mkdir -p "$MODELS" "$MF" "$RAG/app" "$DB_DIR"
echo "설치 루트: $BASE_DIR"
```

## [3] 모델 확보 + 등록 (`ollama create`)

회사망에서 HuggingFace / Ollama 레지스트리가 막히는 경우 **ModelScope**에서 GGUF를 받습니다.
폐쇄망이면 아래 두 `.gguf` 파일을 승인된 매체로 반입해 `$MODELS`에 두세요.

**인터넷 되는 서버(모델 다운로드)**:
```bash
MS="https://modelscope.cn/models"
curl -L --fail --retry 3 -C - -o "$MODELS/Qwen3-4B-Q4_K_M.gguf" \
  "$MS/Qwen/Qwen3-4B-GGUF/resolve/master/Qwen3-4B-Q4_K_M.gguf"
curl -L --fail --retry 3 -C - -o "$MODELS/Qwen3-Embedding-0.6B-Q8_0.gguf" \
  "$MS/Qwen/Qwen3-Embedding-0.6B-GGUF/resolve/master/Qwen3-Embedding-0.6B-Q8_0.gguf"
ls -lh "$MODELS"
```

**Modelfile 작성 + 등록** (인터넷 유무와 무관, 공통):
```bash
# 채팅 모델 (num_ctx: 메모리 여건에 맞춰 조정. 저사양은 4096 권장)
cat > "$MF/qwen3-4b.Modelfile" <<EOF
FROM ${MODELS}/Qwen3-4B-Q4_K_M.gguf
PARAMETER num_ctx 8192
PARAMETER temperature 0.7
PARAMETER top_p 0.8
PARAMETER top_k 20
PARAMETER repeat_penalty 1.05
EOF

# 임베딩 모델
cat > "$MF/qwen3-embedding.Modelfile" <<EOF
FROM ${MODELS}/Qwen3-Embedding-0.6B-Q8_0.gguf
EOF

ollama create qwen3-4b        -f "$MF/qwen3-4b.Modelfile"
ollama create qwen3-embedding -f "$MF/qwen3-embedding.Modelfile"
ollama list
```

> `ollama create` 가 GGUF 읽기 권한 오류를 내면: `chmod 755 "$HOME"` 또는 모델을 `/opt/llm/models`(공용 읽기)로 이동.

## [5] MySQL 8.4 설치 + 기동  ★ (Windows에서 한 작업의 리눅스판)

> 아래는 **포터블 tarball 방식**(Windows zip 설치본과 동일한 개념)입니다.
> Rocky/RHEL 에서 `dnf`로 설치하려면 이 절 끝의 *[대안]* 을 참고하세요.

### 5-1. 필수 라이브러리 + tarball 배치
```bash
# MySQL 8.4 실행에 필요한 런타임 (배포판에 따라 이름 상이)
sudo dnf install -y libaio numactl-libs ncurses-compat-libs 2>/dev/null || \
sudo dnf install -y libaio numactl-libs ncurses-libs

# tarball 반입 후 (예: mysql-8.4.3-linux-glibc2.28-x86_64.tar.xz 를 $DB_DIR 에 둔 경우)
cd "$DB_DIR"
tar xf mysql-8.4.3-linux-glibc2.28-x86_64.tar.xz
rm -rf "$DB_BASE" && mv mysql-8.4.3-linux-glibc2.28-x86_64 "$DB_BASE"
"$DB_BASE/bin/mysqld" --version
```

### 5-2. 설정 파일 `my.cnf` 작성 (한글 utf8mb4 + 메모리 절약)
```bash
cat > "$DB_CNF" <<EOF
[mysqld]
basedir  = ${DB_BASE}
datadir  = ${DB_DATA}
port     = 3306
bind-address = 127.0.0.1          # 로컬(폐쇄망) 전용, 외부 노출 차단
socket   = ${DB_SOCK}
pid-file = ${DB_DIR}/mysql.pid
log-error= ${DB_DIR}/mysql-error.log

character-set-server = utf8mb4
collation-server     = utf8mb4_0900_ai_ci

# --- 메모리 절약 (Ollama와 동시구동 시 OOM 방지) ---
performance_schema        = OFF
innodb_buffer_pool_size   = 128M
innodb_flush_log_at_trx_commit = 2
max_connections           = 50
table_open_cache          = 200

[client]
socket = ${DB_SOCK}
port   = 3306
default-character-set = utf8mb4
EOF
echo "작성됨: $DB_CNF"
```

### 5-3. 데이터 디렉토리 초기화 (root 임시 빈 비밀번호)
```bash
mkdir -p "$DB_DATA"
"$DB_BASE/bin/mysqld" --defaults-file="$DB_CNF" --initialize-insecure --user="$(whoami)"
```

### 5-4. 서버 기동 + 포트 대기
```bash
nohup "$DB_BASE/bin/mysqld" --defaults-file="$DB_CNF" --user="$(whoami)" >/dev/null 2>&1 &
for i in $(seq 1 30); do
  "$DB_BASE/bin/mysqladmin" --socket="$DB_SOCK" ping >/dev/null 2>&1 && { echo "MySQL OK"; break; }
  sleep 1
done
```

> **[대안] dnf + systemd (Rocky/RHEL, 배포판 제공 MySQL 사용 시)**
> ```bash
> sudo dnf install -y mysql-server
> sudo systemctl enable --now mysqld
> # 초기 root 비번 확인(로그) 후 mysql_secure_installation 진행
> ```
> 이 경우 `$DB_BASE/bin/` 대신 시스템 `mysql`/`mysqladmin` 명령을 쓰고, 아래 접속도 `-h 127.0.0.1` 로 하면 됩니다.

## [6] `OLLAMA_LLM` 스키마 + `llmuser`(읽기전용) + 테스트 테이블

## [14] 운영 팁 & 주의

- **메모리(OOM)**: 16GB에서 Ollama(모델 로드 ~3GB) + MySQL 동시 구동은 빠듯합니다. `my.cnf`의
  `performance_schema=OFF`, `innodb_buffer_pool_size=128M`, config.yaml의 `num_ctx=4096` 로 절약했습니다.
- **보안**: `bind-address=127.0.0.1`(DB), API도 `127.0.0.1` 기본. 계정은 **읽기전용**. `.env`는 `chmod 600`.
- **민감정보**: 개인정보·결제정보 테이블은 색인 대상에서 **제외**. 부득이하면 사내 승인 절차를 따르세요.
- **RAG vs 파인튜닝**: 이 시스템은 모델 가중치를 바꾸지 않습니다. 데이터가 바뀌면 **색인만 다시**(`/reindex`) 하면 됩니다.
